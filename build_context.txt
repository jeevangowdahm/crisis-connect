
FULL BUILD CONTEXT
CrisisConnect
Emergency Resource Finder
Agentic AI + Offline-First PWA for finding help in any situation,
anywhere, even without internet



Vision
A mobile-first emergency resource finder that works in disaster zones, rural areas with zero signal, and everyday crises. The app connects people to hospitals, shelters, food banks, police, legal aid, mental health support, and more — powered by AI that understands natural language, not just keywords.

Target Users

Core Features
Natural language search — "I need a place to sleep tonight with my dog"
Instant emergency detection — client-side keyword scan, zero latency (<1ms)
Multi-domain AI triage chatbot — handles medical, legal, mental health, disaster, financial
Offline-first operation — full functionality with no internet via Service Worker + IndexedDB
Voice SOS mode — hands-free, speak your emergency, get spoken results
P2P mesh distress beacon — broadcast SOS to nearby devices via WebRTC (no server needed)
Community resource heatmap — crowd-sourced live availability overlay

Claude Haiku System Prompt — Intent Router

You are an emergency service intent classifier.
Return ONLY valid JSON, no other text, no markdown, no explanation.
 
From the user message, return this exact structure:
{
  "intent": one of [hospital, shelter, food_bank, police, fire,
                    mental_health, legal_aid, domestic_violence,
                    substance_abuse, disaster_relief, general],
  "urgency": "high" | "low",
  "domain": "medical" | "social" | "legal" | "disaster" | "general",
  "keywords_detected": ["array", "of", "matched", "terms"]
}


Claude Sonnet System Prompt — Triage Chatbot

You are CrisisConnect, an emergency triage assistant.
You help people in any crisis: medical, legal, financial, mental health,
domestic violence, natural disaster, homelessness, substance abuse.
 
RULES:
1. Always ask one clarifying question to narrow the exact resource needed.
2. Give 2-3 concrete immediate steps the person can take RIGHT NOW.
3. If situation is life-threatening, say "Call 112 immediately" FIRST.
4. When you identify a specific service type needed, end your message with:
   [SEARCH: {category}] — the app will auto-trigger a search.
5. Never give medical diagnoses. Always recommend professional help.
6. Be warm, calm, non-judgmental. Assume the worst case.
7. User location: {lat}, {lng}. Nearest city: {city}.
8. Keep responses under 150 words. Use plain language.

Offline Search Implementation

// offlineSearch.js
function haversineKm(lat1, lng1, lat2, lng2) {
  const R = 6371;
  const dLat = (lat2 - lat1) * Math.PI / 180;
  const dLng = (lng2 - lng1) * Math.PI / 180;
  const a = Math.sin(dLat/2)**2
    + Math.cos(lat1 * Math.PI/180)
    * Math.cos(lat2 * Math.PI/180)
    * Math.sin(dLng/2)**2;
  return R * 2 * Math.atan2(Math.sqrt(a), Math.sqrt(1-a));
}
 
export async function offlineSearch(category, userLat, userLng, radiusKm = 10) {
  const db = await openDB();
  const services = await db.table('services')
    .where('category').equals(category)
    .toArray();
  return services
    .map(s => ({
      ...s,
      distance_km: haversineKm(userLat, userLng, s.lat, s.lng)
    }))
    .filter(s => s.distance_km <= radiusKm)
    .sort((a, b) => a.distance_km - b.distance_km)
    .slice(0, 5);
}


P2P Mesh SOS Beacon

// meshSOS.js — simplified implementation
const peer = new RTCPeerConnection({
  iceServers: [{ urls: 'stun:stun.l.google.com:19302' }]
});
const channel = peer.createDataChannel('sos');
 
export function broadcastSOS(lat, lng, message) {
  const payload = JSON.stringify({
    type: 'SOS', lat, lng, message, ts: Date.now()
  });
  openPeers.forEach(p => p.channel.send(payload));
}
 
// When SOS received from peer — show alert + log to IndexedDB
channel.onmessage = async (e) => {
  const data = JSON.parse(e.data);
  if (data.type === 'SOS') {
    showReceivedSOSAlert(data);
    await db.mesh_log.add({ ...data, received_at: Date.now(), relayed: false });
  }
};

Streaming Implementation (FastAPI)

# main.py — /chat endpoint with SSE streaming
from anthropic import Anthropic
from fastapi.responses import StreamingResponse
import json
 
client = Anthropic()
 
@app.post("/chat")
async def chat(body: ChatRequest):
    messages = body.messages        # full conversation history from frontend
    system = TRIAGE_SYSTEM_PROMPT.format(
        lat=body.lat, lng=body.lng, city=body.city
    )
 
    async def stream_response():
        with client.messages.stream(
            model="claude-sonnet-4-20250514",
            max_tokens=300,
            system=system,
            messages=messages,
        ) as stream:
            for text_chunk in stream.text_stream:
                yield f"data: {json.dumps({'text': text_chunk})}
 
"
        yield "data: [DONE]
 
"
 
    return StreamingResponse(
        stream_response(),
        media_type="text/event-stream",
        headers={"Cache-Control": "no-cache", "X-Accel-Buffering": "no"}
    )


Auto-Search Trigger Parsing (React)

// ChatBot.jsx — parse [SEARCH: category] from streamed response
function parseAutoSearch(fullText) {
  const match = fullText.match(/[SEARCH:s*(w+)]/i);
  if (match) {
    const category = match[1].toLowerCase();
    // Auto-fire the search bar with this category
    triggerSearch(category);
    // Remove the tag from displayed message — clean UX
    return fullText.replace(match[0], '').trim();
  }
  return fullText;
}
 
// Usage in SSE stream handler:
eventSource.onmessage = (e) => {
  if (e.data === '[DONE]') {
    const cleanText = parseAutoSearch(accumulatedText);
    appendMessage({ role: 'assistant', content: cleanText });
    return;
  }
  const { text } = JSON.parse(e.data);
  accumulatedText += text;
  updateStreamingBubble(accumulatedText);
};
